# Delivery roadmap

Reviewable sequence; none of these phases is accepted solely because this document exists.

1. Verify and review the current database foundation and dependency posture using PostgreSQL 16, CI and independent review.
2. Design and build authentication, revocable sessions, trusted tenant derivation and centralized RBAC, with explicit administrative bootstrap and tests.
3. College onboarding, invitation and institutional configuration.
4. Student profiles, authorized coordinator scope and private document storage.
5. Company and placement-drive management.
6. Explainable deterministic eligibility, then race-safe student registrations.
7. Audited recruitment states, offers and actual placement confirmation as separate events.
8. Role-specific dashboards, reports, notifications with evidence-based delivery states and audit.
9. Production security, legal/privacy/accessibility work, operational configuration, backups, E2E tests and independent review.

Each step needs security and data integrity review, relevant real tests, documentation, CI and owner approval. No AI-based eligibility, selection or placement decisions. The existence of a later roadmap item is not evidence it is implemented.
